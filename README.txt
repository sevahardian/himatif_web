# Website Statis HIMATIF UNTIDAR

Website multipage HTML + CSS sesuai studi kasus:
- Tanpa JavaScript
- Tanpa backend/database/login
- Responsive desktop & mobile
- Tanpa gradient
- Palet solid: Biru Cerah, Biru Magenta, Biru Sapphire, Putih
- 8 halaman: Home, About, Visi & Misi, Struktur, Program, Dokumentasi, Video, Contact

## Struktur
- index.html
- about.html
- visi-misi.html
- struktur.html
- program.html
- dokumentasi.html
- video.html
- contact.html
- style.css
- assets/img/14. LOGO HIMATIF.png
- assets/struktur-kominfo.png

## Catatan pengisian aset
Halaman Struktur sudah memiliki 11 slot. Ganti placeholder 10 bagian lainnya dengan gambar struktur yang diberikan.
Halaman Dokumentasi juga sudah memiliki slot galeri. Ganti placeholder dengan foto kegiatan asli.
Video menggunakan embed YouTube yang diberikan pada studi kasus.

## Cara menjalankan
Buka `index.html` langsung di browser. Tidak membutuhkan XAMPP atau server.
